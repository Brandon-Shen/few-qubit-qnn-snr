## One issue found outside Task 5's scope, flagged rather than fixed

**Status update (post-Task-5, resolved):** `\includegraphics{figures/fig0_el_primary.pdf}`
(label `fig:el-primary`, in the H2 Results subsection) referenced a file
that did not exist anywhere in this repository at the time Task 5 was
completed. This figure predated Task 5 (it was not among Tasks 1--4's
outputs, and is not one of fig6--fig10); the caption already in
`main.tex` described fold-change indices $I_{EL}/J_{EL}$, so it appeared a
prior editing pass wrote the caption and `\includegraphics` call without
ever generating the corresponding file. Per the "do not invent" guardrail,
this was not fixed by inventing a replacement figure at the time. **It has
since been reconstructed reproducibly from frozen machine-readable data**
in a follow-up task
(`verification/fig0_el_primary_regeneration.md`): the same production
interaction-index code (`qnn_snr.stats.interactions.compute_interaction_indices`)
was independently cross-checked against a from-scratch numpy
recomputation on `results/pointwise_gradient_statistics.parquet`
(end-to-end-mode only) and `results/raw/exact.parquet`, both agreeing to
`atol=1e-9` and rounding to the caption's existing values
($I_{EL}\to1.034$, $J_{EL}\to1.242$) without those values ever being used
as inputs. `paper/scripts/structural_check.py` no longer reports this
figure as missing.
